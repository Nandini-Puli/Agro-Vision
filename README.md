# Agro Vision 🌱

Agro Vision is an AI-powered smart farming platform designed to help farmers make better agricultural decisions using real-time weather data and artificial intelligence.

## Features

-  Live weather information using OpenWeatherMap API
-  AI-based crop recommendations using Google Gemini API
-  Plant disease detection using a Hugging Face model
-  Treatment suggestions for detected diseases
-  Location-based weather analysis
-  Water requirement suggestions
-  Farming risk and warning insights
-  Responsive and user-friendly interface

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python Flask

### APIs and AI Models
- Google Gemini API (Crop Recommendation and Disease Treatment Suggestions)
- OpenWeatherMap API (Weather Data)
- Hugging Face Model (Plant Disease Detection)

## How It Works

### Crop Recommendation
1. Fetches real-time weather data.
2. Sends weather information to Google Gemini AI.
3. Analyzes climate conditions.
4. Recommends suitable crops along with farming advice.

### Disease Detection and Treatment
1. User uploads an image of the plant leaf.
2. The image is analyzed using a Hugging Face model.
3. The model predicts the disease affecting the plant.
4. The detected disease is displayed on the same page.
5. Appropriate treatment recommendations and preventive measures are provided to the user.

## Key Features
